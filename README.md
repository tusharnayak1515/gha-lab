# Difference between GitHub-hosted and self-hosted runners
--- 
GitHub-hosted runners are managed by GitHub. We don't have to worry about maintenance, cleanup, etc.

Self-hosted runners are self managed virtual machines where the workflows execute. So, there's much more risk of it getting misused or of getting accessed unwantingly. Also, we have to manage these and do the cleanup work. Good thing is we have more control over it and hence, we can set it up according to us.
